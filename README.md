# 📊 Sales Forecasting using Machine Learning

## 📌 Project Overview
This project predicts future sales using historical retail data.
Machine learning models are used to analyze trends and forecast future demand.

---

## ⚙️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---

## 🤖 Models Used
- Linear Regression
- Random Forest Regressor

---

## 📊 Key Features
✔ Data cleaning and preprocessing  
✔ Time-based feature engineering  
✔ Model training and evaluation  
✔ Visualization of sales trends  
✔ Future sales prediction  

---

## 📈 Results
- Linear Regression performed better than Random Forest  
- Sales show seasonal patterns (higher in Nov–Dec)  
- Future predictions indicate an increasing trend  

---

## 💡 Business Insights
- Helps in inventory planning  
- Supports marketing strategies  
- Reduces overstock and stock shortages  

---

## 🚀 Conclusion
Machine learning can effectively forecast sales and help businesses make better decisions.
